# Alzheimer’s Prevention

A community resource on preventing Alzheimer’s disease: risk factors, trial evidence, prevention trials and data. Sister site to [apoe4.science](https://apoe4.science).

Maintained by Mahdi Moqri, PhD, in a personal capacity.

## Editing

Edit content in `tools/build.py`, then rebuild from the repository root:

```
python3 tools/build.py
```
