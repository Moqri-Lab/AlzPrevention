Prevention trials

Drug trials before symptoms

Trials that treat people who have Alzheimer’s changes, or very high genetic risk, before memory problems begin. Ongoing trials first.

TrialDrugWhoStatus and result
TRAILBLAZER-ALZ 3DonanemabAbout 3,000 cognitively unimpaired adults with Alzheimer’s pathologyFully enrolled Primary completion expected October 2027.

HT-4253Oral LRRK2 inhibitor112 biomarker-positive APOE4 carriers in Abu DhabiRecruiting 48-week Phase 2a, started May 2026.
A4 StudySolanezumabMore than 1,100 adults with amyloid but no symptomsNo benefit Did not slow cognitive decline. ↗
API ColombiaCrenezumab252 members of a Colombian family with an early-onset PSEN1 mutationNo significant benefit Numerical trends favoured the drug, none significant (2022). ↗
Generation Study 1Umibecestat or CAD106Cognitively unimpaired APOE4 homozygotes aged 60–75Stopped 2019 Umibecestat worsened cognition slightly; program ended.

Status changes often; each trial name links to its ClinicalTrials.gov record. To volunteer, search ClinicalTrials.gov or use the Alzheimer’s Association’s TrialMatch.
